# Políticas de Mr. Trámite

## Política de cobro
- El cliente **no paga nada** hasta tener cita confirmada.
- Si no se logra cita, el servicio es gratuito.
- El precio se comunica antes de iniciar el trámite (sin sorpresas).

## Política de servicio
- Mr. Trámite gestiona a nombre del cliente, no asesora jurídicamente.
- El cliente debe proporcionar la documentación requerida.
- Los tiempos de cita dependen de la institución, no de Mr. Trámite.

## Política de datos
- Los datos del cliente se usan exclusivamente para el trámite solicitado.
- No se comparten con terceros.
- (Pendiente: definir retención y eliminación conforme a LFPDPPP si aplica).

## Política de reembolso
- Como el cobro ocurre solo después de confirmación, los reembolsos aplican únicamente si:
  - La cita fue cancelada por error de Mr. Trámite.
  - El servicio no se entregó conforme a lo acordado.

## Política de comunicación
- Canal principal: chat en la web.
- Tiempo de respuesta objetivo: menor a 1 hora en horario laboral.
- No se realizan llamadas frías.
